# High_Altitude_Voltage
This project aims to create a system for applying electrically conductive substances to various surfaces — Этот проект нацелен на создание установки наносящей токопроводящие вещества на различные поверхности 

> [!CAUTION]
> ### Предупреждение
> Такая схема делается на опыте полученном при самостоятельном обучении
> поэтому автор не гарантирует её 100% работоспособность и 100% защиту от ударов тока.

## ✨ Основные характеристики (Planned Specifications)
- **Входное напряжение (Input):** 220~230 AC / 10 A
- **Выходное напряжение (Output):** 40 kV DC / 0.6~0.4 мА
- **Топология схемы:** Преобразователь - Регулятор [переменный резистор - вольт/ампер -- метр - выкл/вкл] - ZVS-драйвер - Строчный трансформатор - [Делитель напряжения - Стрелочный вольтметр]
