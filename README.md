## ✨ Основные характеристики (Planned Specifications)
- **Входное напряжение (Input):** 220~230 AC/ 10 A
- **Выходное напряжение (Output):** 10 - 80 kV
- **Топология схемы:** Фильтра - Выпрямитель - H-мост - Гальваническая развязка - Умножитель напряжения - Баласт
